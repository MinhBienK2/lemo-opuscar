# Lessons: the reusable ones

Distilled from the retro records in [`retro/`](retro/). Each line is a rule; each guard is what now enforces it. Read this before building a film.

- **A mechanical mistake needs a check, not a rule.** — Guard: `core/render/drawcheck.mjs` catches a drawing call with the wrong argument count or inverted corners.
- **A loop that is a list of steps gets skipped; a loop that is one command gets run.** — Guard: `sh core/render/review.sh <folder>` is the whole review loop, and `TECHNIQUE.md` §8 points at it.
- **"Verified" is a word you may only write with the check output in hand.** — Guard: `DIRECTOR.md` §11 and `CODING_STANDARDS.md` R4.
- **Never ship before the guard runs.** — Guard: CI (`.github/workflows/films.yml`) and the pre-commit hook (`tools/install_precommit.sh`) run on every push, before a commit reaches the repository.
- **Edit files with the file-editing tools; a shell write can truncate a file before it fails.** — Guard: `CODING_STANDARDS.md` R1 — a judgement rule, no check can replace it.
- **A codemod is not applied until you have re-read the file it touched.** — Guard: `CODING_STANDARDS.md` R2 — report the edits that did not land.
- **Never commit a file the user has modified.** — Guard: `CODING_STANDARDS.md` R3 — stage your own change only, never `git add -A` on a dirty tree.
- **Start a long job in the background and keep working; never poll it with `sleep`.** — Guard: `CODING_STANDARDS.md` R5.
- **Read the reference film's file map before reading the reference film.** — Guard: `TECHNIQUE.md` §13 "Anatomy of a reference film".
- **Use the tools the library already has: `core/render/still.mjs` and `core/render/sheet.py`, not a hand-rolled ffmpeg montage.** — Guard: `core/render/review.sh` builds the contact sheet with them; `CODING_STANDARDS.md` R10 and the supervisor's R10 report catch the montage written by hand.
- **Derive a convention from the code in front of you, not from memory of the library.** — Guard: `drawcheck` reads each film's own `rect` helper, because the signature differs per style.
- **Every source in a research file must be traceable.** — Guard: `tools/check_citations.py` requires DOI, PMID, arXiv or a URL per entry.
- **A caption that names a state must be gated on that state** — the label and the state share one clock. — Guard: `DIRECTOR.md` §11 (a doc rule: no check can see that a label lies about the picture); the cases are in the retro records.
- **A value that changes every frame must not be rendered as text** — a label that ticks is a new text piece every tick, and the reading check needs each piece to hold. — Guard: `core/render/review.sh` (readcheck) reports it; the rule is in `retro/2026-10-30-tap-02.md`.
- **Every visible string goes through `text()`** — only `text()` registers the box the reading check measures, so a raw `fillText()` is a string no check can see. — Guard: `core/render/drawcheck.mjs` reports a raw `fillText()` in the shot file; `DIRECTOR.md` §11.
- **A marker stroke goes behind the words it marks.** — Guard: none — the contact sheet shows it; recorded in `retro/2026-10-30-tap-02.md`.
- **A blurred picture is a look; blurred letters are a mess** — a transition may smear the frame, but the words are drawn again, sharp, on top. — Guard: none (the picture shows it); `DIRECTOR.md` §10.
- **A rig option nobody reads is a pose that never happens** — when a pose looks stiff, check that the rig consumes what the shots pass it. — Guard: none (a code review finds it); recorded in `retro/2026-10-30-tap-02.md`.
- **The bottom of the frame belongs to the subtitles** — nothing else may be drawn there, and a caption under the words is the same sentence twice. — Guard: `core/render/readcheck.mjs --band 880`, wired into `core/render/review.sh`; `DIRECTOR.md` §11.
- **The picture carries labels and numbers, not the voice** — the subtitle already says the sentence. — Guard: `DIRECTOR.md` §11 (a writing rule; no script can decide it).
- **Measure the string against the box it lives in, not the box against the frame** — a clipped panel cuts a title in half without any error. — Guard: none — the contact sheet shows it; recorded in `retro/2026-10-30-tap-02.md`.
- **A gate that cannot fail the build is decoration.** — Guard: the film's own `build.sh` exits with the review's status; `CODING_STANDARDS.md` R4.
- **The rationale of a film belongs with the film.** — Guard: `.gitignore` keeps `films/*/TREATMENT.md` and `channels/*/*/TREATMENT.md` trackable.
- **A copied folder keeps the previous episode's identity** — its treatment, research, title and credits. — Guard: `core/render/filmcheck.mjs` reports the identity files that are byte-identical to another episode's, and the files that name different episodes; `review.sh` runs it first.
- **A build script that keeps the other episode's name ships the film under that name.** — Guard: `core/render/filmcheck.mjs` — the name the build writes the movie under must belong to no other film.
- **A research file that forbids a number in writing is a research file the film ignores.** — Guard: `tools/check_claims.py` reads the research file as sentences; a forbidding sentence supports nothing, and a conditional sentence demands its qualifier on screen.
- **A number attributed to a year must find that year beside it in the source.** — Guard: `tools/check_claims.py` — the year rule.
- **The source's wording of a number is the source's wording, not the film's.** — Guard: `tools/check_claims.py` reports the pair; the judgement is a reader's — `CODING_STANDARDS.md` R6.
- **The index must name the file the build wrote.** — Guard: `tools/gen_films_index.py` writes `FILMS.md` from the manifests; `tools/check_films_index.py` compares every manifest with the file on disk, the runtime `ffprobe` measures and the index with the manifests.
- **A rule with a witness beats a rule on paper** — the supervisor reads the running session's own tool log every fifteen minutes and reports what it broke. — Guard: `tools/supervise.sh`.
- **The research file must be consistent with itself** — a bullet written twice, a "mục N" that points at the wrong section. — Guard: `tools/check_facts.py`; a check that cannot fail the build is decoration.
- **A check that cries wolf gets switched off** — a name used but never imported is a ReferenceError, but the first check for it reported 31 false positives on `host-toon-test`; it was reverted, and the proposal waits until it is quiet on every film. — Guard: none — recorded in `retro/2026-10-30-tap-03.md`.
- **One module knows where the films are** — a tool that globs `films/` finds the one-shots and misses the episodes, and a tool that counts levels breaks the day the layout moves. — Guard: `core/render/films.mjs`; every tool, CI step and hook asks it for the list.
- **The marker decides what a folder is; the depth never does** — a channel holds `CHANNEL.md` and no `build.sh`, a film holds a build. — Guard: `core/render/films.mjs` classifies by marker, so a channel may hold its episodes at any depth.
- **A copy of the channel's shared code inside an episode is a second version that drifts** — the episode that reaches the channel and the one that carries a copy no longer draw the same picture. — Guard: `core/render/new_episode.sh` attaches the shared code instead of copying it; the judgement is `CODING_STANDARDS.md` R7.
- **A supervisor that watches the wrong session reports nothing — and "nothing was broken" reads as "nobody was looking".** — Guard: `tools/transcript.py` reads both transcript shapes; `tools/supervise.sh` finds each tool's session folder by its own slug.
- **Wait for the agent, never for the file.** A subagent reports when it is done; asking the filesystem instead is a poll loop that burns the turn and decides nothing. — Guard: `CODING_STANDARDS.md` R9; `tools/supervise.sh` reports the same command five times over.
- **Two agents never write one file** — while a subagent owns a file, the parent reads it and waits. — Guard: `CODING_STANDARDS.md` R9.
- **A gate that asks the impossible is a prison, not a gate.** A blind viewer cannot name "a drop falling from a towel's edge" on its own; asking for that exact name fails the same prop in every round. — Guard: `review.sh --props` splits props into two tiers from their own names; a part only fails when the image shows a different real object.
- **A step with no tool is a step nobody can skip and nobody can count.** — Guard: `review.sh --storyboard` grades the framing, signs it, caps it at five rounds and stamps it; `gate.py` holds the stamp.
- **A gate that cannot be passed needs a way out that is written down.** — Guard: the director's cut — a written scope of what was cut, ending in `VERDICT: PASS` — is the storyboard's PASS.
- **The episode's rationale is the episode's deliverable** — an episode untracked by a blanket ignore rule lives on one disk. — Guard: `tools/check_tracked.py`; `.gitignore` keeps only the regenerable review frames out.
- **A film that exists has a length** — an empty runtime slips a format check that only tests non-empty values. — Guard: `core/render/filmcheck.mjs`.
- **The file without a number is the latest verdict** — when it is not, a reader reads a round that was already superseded. — Guard: `core/render/filmcheck.mjs` reads the review folder.
- **An episode starts empty of the previous episode's identity** — a copied folder carries the old treatment, research, title and name with it. — Guard: `core/render/new_episode.sh` writes the templates of the episode and nothing else; `core/render/filmcheck.mjs` reports the identity files that are byte-identical to another film's.
- **The index is generated from the manifests, never written by hand** — a hand-written table drifts from the films the moment one is re-rendered. — Guard: `tools/gen_films_index.py` writes `FILMS.md`; `tools/check_films_index.py` compares every manifest with the file on disk and the index with the manifests.
- **A check that could not check says so and exits non-zero** — a skipped audit that returns success reads as a pass. — Guard: `core/render/drawcheck.mjs` says what it could not check and exits non-zero.
- **A guard that stops finding what it watches is off, not passing** — the drawing audit lost its `rect` rule when the helper moved to the channel's rig, and the step still said ok. — Guard: `core/render/drawcheck.mjs` follows the episode's relative imports; a helper that is found but not applied counts as not restored.
- **A missing model skips a check; a mismatch fails it** — `set -e` turned "the whisper model is not on this drive" into a failed gate. — Guard: `core/render/review.sh` captures the checker's status: a model error skips, a mismatch fails.
- **A blank 3D panel is not a render** — a WebGL context that exists but whose shaders do not validate draws white and every check stays green. — Guard: `core/render/page.mjs` recognises the page's own WebGL failures in the log and names the fix (`LEMO_ANGLE=swiftshader` on Linux, `metal` on macOS); `core/render/browser.mjs` probes the context itself.
- **A deliverable that git will not take is not delivered** — the treatment stayed on disk and out of the repository because a `.gitignore` negation matched one level. — Guard: `tools/check_tracked.py` asks git whether each film's treatment can be committed.
- **A witness that looks in the wrong place watches nothing** — the supervisor's `find -newermt '-2 days'` never matched, so it never found the film under production. — Guard: `tools/supervise.sh` asks the discovery module for the films and computes the date with `date -d`.
- **A check that needs a local artefact skips when the artefact is not there** — the speech is generated on the machine and is not in the repository, so a fresh clone cannot run the voice check; failing on a missing file hides the real findings. — Guard: `core/render/review.sh` skips the voice step with a message when the film has no generated voice, the way it skips a missing model.
- **A file the films import must be parsed too** — the channel's shared rig and the cast module are code; a syntax error in them shipped while the parse step walked only the films' own `src/`, and copying files by basename meant one `film.js` was parsed while the others never were. — Guard: the CI parse step covers `channels/`, `films/`, `core/cast/` and the styles, and copies each file under a unique name.
- **An unfilled template placeholder is not a written file** — `<structure>`, `<Author>` or `<doi or link>` in a file is an unwritten document, not a completed deliverable. — Guard: `core/render/filmcheck.mjs` rejects template placeholders; `tools/check_citations.py` rejects unexpanded placeholders.
- **The voice check is not a rubber stamp** — never use `asr` to mask mispronounced or slurred Vietnamese words; fix the audio or adjust pronunciation in `say`. — Guard: `CODING_STANDARDS.md` R8 and `channels/tram-nghi-nhieu/voice/asr_vi.py` (logs `NOTE` on override).
- **The delivery review must verify the sources** — a citation without DOI or URL passes locally if the review gate forgets to run the check. — Guard: `core/render/review.sh` runs `tools/check_citations.py`.
- **A delivered movie must not be older than the source code** — editing `src/film.js` after a build without re-rendering leaves a stale movie on disk. — Guard: `core/render/review.sh` compares mtime of `$MP4` against `src/` and `voice/`.
- **True Peak audio must not exceed the ceiling** — loudness normalisation can miss its ceiling when peaks clip. — Guard: `core/render/review.sh` measures `ebur128=peak=true` and checks True Peak ceiling.
- **A multi-line shot must not collapse its cues onto the first line's clock** — every line in a compound shot drives its own elements with `L(id).t0`, so a 13-second shot never freezes for 10 seconds. — Guard: `skill://tram-nghi-nhieu` and `CHANNEL.md` §9.
- **A conclusion or punchline label must not appear before the voice reveals it** — anti-spoiler rule; labels and outcome stamps share the clock with the spoken reveal. — Guard: `skill://tram-nghi-nhieu` and `CHANNEL.md` §9.
- **A manifest title must match the spoken and research thesis** — a scaffold title that advertises a different claim from the film drifts unchecked. — Guard: `core/render/filmcheck.mjs`.
- **An observational attenuation is never an absolute in the script** — "miễn nhiễm" or "không bao giờ bị ảnh hưởng" stated as fact violates observational study limits. — Guard: `tools/check_claims.py` scans `voice/lines.json` for forbidden phrases; `FACTS.md` Scope boundaries apply to the voice.
- **A marker stroke goes behind the text it emphasizes, never cutting through glyphs** — a strike or underline drawn on top obscures legibility. — Guard: `skill://tram-nghi-nhieu`.
- **A 3D scene film draws in scene graphs, not 2D canvas rects** — a drawing checker that fails because 2D canvas helpers are absent breaks every 3D film. — Guard: `core/render/drawcheck.mjs` recognizes 3D scene rigs and `rrect` helpers; `channels/tram-nghi-nhieu/rig/render.js` exports `rect` and `rrect`.
- **A citation checker must accept standard academic citation forms** — rejecting `PMID 16676778` because it lacks a colon turns valid literature citations into failed builds. — Guard: `tools/check_citations.py` allows optional colons in `IDENTIFIER` regex.
- **The film manifest must enforce runtime format and match treatment title** — unvalidated runtime strings (`1058.0s`) and title drift break index generation downstream. — Guard: `core/render/filmcheck.mjs` checks `runtime` format (`M:SS`) and checks `film.json` title against `TREATMENT.md`.
- **Never stop or hand off while an independent review is FAIL** — presenting a "final handoff" when the reviewer gave 4.0/10 requires user rescue. — Guard: `channels/tram-nghi-nhieu/CHANNEL.md` and `AGENTS.md` Delivery Gate invariant.
- **A check that crashes is not a verdict about the film** — a dead browser and a broken film look the same to the reader of a stack trace, and the reader goes hunting for a defect that is not there. — Guard: `core/render/readcheck.mjs` and `core/render/scenecheck.mjs` say "COULD NOT RUN" and exit 2; `core/render/review.sh` prints "COULD NOT RUN — not a verdict about the film" for exit 2.
- **A check that runs on files that change under it measures a film that never existed** — the agent is still editing while the check reads, and the result is about a mixture of two versions. — Guard: `core/render/sourcewatch.mjs` fingerprints `index.html`, `src/*.js` and `voice/lines.json` before the page opens and compares them after; a changed file voids the result.
- **A page that reads a whole film in one synchronous loop starves its own GPU** — 4 400 renders without a return to the event loop grow the command queue until the renderer can die mid-read. — Guard: `core/render/readcheck.mjs` reads the film in chunks of 120 frames, so the browser breathes between them and a crash names the second it died on.
- **A broken pointer is silent** — nobody notices that a document points at a file that is not there, and the rule that pointer carried reaches nobody. — Guard: `tools/check_doc_links.py` resolves every markdown link of the library; the pre-commit hook and the CI run it.
- **A check that cannot fail is not a check** — a CI step that diffs a symlink against its own target always passes, so the two copies of a skill can drift without anyone noticing. — Guard: the CI step checks the symlink and the two real paths, not the contents of two folders.
- **A verdict that flips while the picture did not change is the reviewer changing its mind** — and the director reads it as a new defect, so the fix breaks a prop that was right. — Guard: `channels/tram-nghi-nhieu/tools/review.sh --props` records the hash of `src/props.js` in each round and reports the props whose verdict changed while the code stood still.
- **A check that draws the same frame twice pays for it twice** — the reading check drew every frame itself and then asked `TEXTS` for the text, and `TEXTS` drew the frame again before answering; on a 3D film that doubled the check's cost. — Guard: `core/render/readcheck.mjs` counts the draws `TEXTS` makes and draws the frame itself only when `TEXTS` does not draw.
- **The subtitle is not a text piece** — its hold is set by the `.srt`, so a film that hands the subtitle box back to `TEXTS` has every spoken line measured as a too-short text. — Guard: the channel's rig drops any box with `id: 'sub'` from `TEXTS` (`channels/tram-nghi-nhieu/rig/render.js`).
- **A check that measures the picture can lose the machine to the picture** — the reading check measures text boxes, but it drew at the film's shipping quality (2× supersampling) and lost the browser 91 s into a 3-minute film on a 6 GB GPU; at 1× it read the whole film. — Guard: the channel says how the reading check must draw (`channels/tram-nghi-nhieu/scene_rules.json`: `"readcheckQ": "ss=1"`), and `core/render/review.sh` passes it on.
- **A scripted edit must count its matches** — a snippet that occurs twice is how an edit lands on the wrong place, and a shell write can truncate the file before it fails. — Guard: `python3 tools/replace.py <file> <old-snippet> <new-snippet>` refuses to write unless the snippet occurs exactly once, and renames a whole new file over the target.
- **A rule must count what it claims to count** — the supervisor's R1 reported the files a command named, not the files it wrote, so it showed 475 violations where the truth was 34; a report nobody can read is a report nobody acts on. — Guard: `tools/supervise.sh` reads the write position (`open(x, 'w')`, a redirect, `sed -i`, `cp`/`mv`, `os.replace`) and reports the files written, one line per rule.
- **A number the index publishes is a number an instrument measured** — a runtime written into `film.json` by hand is a guess, and the check that compares a manifest with `ffprobe` skips the very films whose movies are not in the repository. — Guard: `core/render/new_episode.sh` writes the measured runtime into the manifest; `core/render/review.sh` compares the manifest with the movie in front of it.
- **A verdict must follow the picture, not a word about the picture** — the props review failed a prop that is a human hand because the blind namer called it a foot and rated its own guess "low confidence"; three namings of the same images gave five props five different verdicts. — Guard: the props rubric judges the image, a low-confidence name is not a verdict, and a prop the namer was unsure about gets a second namer.

- **A label has to sit on the line that names it** — a label on the wrong beat says one thing while the voice says another, and no gate that reads only the storyboard can see it. — Guard: `channels/tram-nghi-nhieu/tools/check_labels.py` finds the line that names each label and reports the label when it sits more than one beat early.
- **A way out of the rounds must still say something about the film as it is now** — a director's cut written before the last edit of the code closes the gate on code nobody looked at. — Guard: `channels/tram-nghi-nhieu/tools/gate.py` refuses a cut older than the code it judges.
- **A check that counts must count the thing it names** — the rule says numbers *spoken*, the check read the written column, and the film was reported twice as dense as it sounds. — Guard: `core/render/scenecheck.mjs` counts `l.say || l.text`.
- **A path walked with `dirname` stops at `.`** — the review gate looked for the channel folder by climbing with `dirname`, and on a relative folder it reached `.` and stayed there, so the gate spun in silence for three hours. — Guard: `core/render/review.sh` walks up with `cd`, so the path is absolute.
- **A step that hangs forever looks like a step that is working hard** — a hung check prints nothing, so nothing says it has died. — Guard: `core/render/review.sh` gives every step a wall clock and reports the kill as "could not run", never as a verdict about the film.
- **A round of review must say what it fixed** — the report was 39,000 characters and nothing compared it with the last one, so the agent could not see that 16 of 22 failures were already gone. — Guard: `channels/tram-nghi-nhieu/tools/check_progress.py` prints what the last round fixed, what is still open and what is new.
- **A render that loses frames says nothing** — four browsers at ss=2 overrun a 6 GB GPU, the browser dies mid-film, ffmpeg closes the segment, and the movie is short by an unknown number of frames while `ffprobe` still reads it. — Guard: `core/render/new_episode.sh` renders with two workers, the number the channel's own demo uses.
- **A checker must ask, not assume** — the library asks every treatment for the library's own shape, and a channel that has its own template then fails sixteen times for doing everything right. — Guard: pending — the check should read the channel's own rules beside its `CHANNEL.md`.
- **Two paths must be measured from the same place before they are compared** — the supervisor compared an absolute film folder with the relative paths agents write, so it never matched, fell back to "the newest session", and reported on the wrong session for hours. — Guard: `tools/supervise.sh` normalises both sides against the library root, takes `SUPERVISE_FILM`, and prefers the main session over a subagent's transcript.
- **A check that answers "yes" to everything is not a check** — the spoken column of every line was empty, and an empty string is a substring of every word, so the new check passed in silence while three real defects sat in the film. — Guard: `check_labels.py` skips empty lines and proves itself with `--selftest`, six real lines including that trap.
- **A number on screen is a promise to say it** — the film drew `288 g`, `88 g` and `50 %` while the narrator said none of them, against the episode's own FACTS.md; no machine looked at the relation, so it passed two gates. — Guard: `check_labels.py` fails a label that draws a figure the words never say, and both gates run it.
- **The cost of a long session is re-reading, not making** — 186 reads of three source files to find one place to edit, while the film itself took a fraction of the time. — Guard: `tools/supervise.sh` counts the reads per file and reports R11 from fifteen; read a range, keep a map of the code.
- **A frame that changes is not a story that moves** — a dashed ring that spins was the only thing acting in a beat, and the gate counted it as action while the reviewer saw a still room. — Guard: `beatsheet.mjs --motion` measures each line with the camera shift taken out; it is a hint, and only beat marks can make it a verdict.
- **The report must not be the one that counts the rounds** — three picture reviews of one episode all wrote `ROUND: 1/5`, because the reviewer filled in a field it was never told, and a report that always says round 1 cannot tell a loop from a first attempt. — Guard: `review.sh` writes the `ROUND:` line itself, from its own round number and its own limit.
- **A check that passes an empty file passes the film** — the research file of one episode was still the untouched template, and every gate said yes: no duplicated bullet, no wrong cross-reference, the file exists. The judge that reads it had nothing to object to. — Guard: `check_research.py` fails a leftover placeholder, a missing claim or a missing source, and the outline gate runs it before a review round is spent.
- **A mention is not a slot** — the gate looked for the literal `<viết:` anywhere, so the template's own first line, which names the placeholder it asks for, turned a finished treatment away. — Guard: a placeholder inside backticks is a mention; `check_treatment.py` and `filmcheck.mjs` look outside the backticks.
- **Look at the sheet, not at the frame again** — 1 032 images, 436 MB of an 860 MB transcript, and one frame opened seventeen times, while the channel already builds a sheet of twelve frames per page. — Guard: `CODING_STANDARDS.md` R12, and the supervisor counts image reads per file.
- **An encyclopedia is a cross-reference, not a source** — every claim of one episode's research file cited Wikipedia; the machine only asked whether a source could be looked up, and the peer had a primary datasheet in hand that it never cited. — Guard: `check_research.py` fails a claim whose every link is Wikipedia, and the outline critic says what a reliable source is.
- **A character class written by hand cuts the language it does not know** — `[A-ZĐỘ_]+` split the Vietnamese score keys into fragments, so no key ever matched and the comparison between two review rounds said nothing about the scores. — Guard: `check_progress.py` reads the key with `\w+` and proves itself with `--selftest`.
- **A check that no one runs is a check that is broken in silence** — twelve of the library's checks had no way to show that they catch anything, so a broken one looked like a passing one. — Guard: `tools/run_selftests.sh` runs every selftest and fails when a checker has none.
- **A script that is running must not be edited under it** — a shell reads a script as it executes it, so an edit shifts the bytes and the running shell resumes at an offset that no longer means the same thing; the round then dies on a byte offset and the failure looks like the film's fault. — Guard: `CODING_STANDARDS.md` R13 — write the new file beside the old one and swap it in when the run ends.
- **A comparison only counts when it reaches the one who needs it** — the tool knew what the last review round fixed and what was still open, but the report went to the controlling session's screen while the reviewer started from zero, so a fixed blocker was reported again. — Guard: `channels/tram-nghi-nhieu/tools/review.sh` writes the comparison to `PROGRESS.md` in the reviewer's own working folder.
- **A check must not certify what it never opened** — the timing check was written for the channel's old 2D format, and after the 3D rebuild it still printed "verified" about films it had never read. — Guard: `tools/check_timing.py` says it does not know the format and that no rule was applied, and exits 2; the channel ships its own check for its own format.
- **A machine can only guard what it can read** — the research file forbade a ranking in words, and only forbidden *numbers* were checked, so the film said the forbidden sentence and every gate said yes. — Guard: `channels/tram-nghi-nhieu/tools/check_voice_facts.py` compares the forbidden phrases with the words the film speaks.
- **The document the gate reads is not the film** — a session rewrote the narration and the code, left the treatment behind, and the next round would reject a film that was already right. — Guard: pending — the outline gate should read the treatment beside the narration and the code.
- **One call must not carry two names for the same thing** — the critic template said `SCENE-REVIEW.md`, the task line said `REVIEW.md`, and the tool read only one; when the critic followed the template, the fallback copied a file of warnings into the report and the round's work was lost. — Guard: the templates name the file the tool reads, and the tool takes either name.
- **A check that blocks a correct film is worse than no check** — the number-to-words helper read "45" as "bốn mươi năm", so a label drawing "45 °C" was reported as a figure the voice never says, while the voice said "bốn mươi lăm độ" exactly as the research file demands. — Guard: `check_labels.py` says "lăm" for the five in a compound number, and proves it with `--selftest`.
- **A report is written by a person, so the tool must read the ways people write** — the critic answered with a bold "**VERDICT: REJECT**" and the tool looked for a plain line, so a round that had been judged was filed with no verdict, and a bold PASS would have thrown the round away. — Guard: `review.sh` and `gate.py` read the verdict in both forms.
- **A round of review must say what it cost** — the picture reviewer opened 201 single frames to look at 60, one of them nine times, and nothing said so. — Guard: the critic has an image budget, and `review.sh` counts the reads from the reviewer's own transcript and prints them.
