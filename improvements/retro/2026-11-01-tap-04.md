# Retro — building Tập 04, ten minutes long (2026-11-01)

The session this record is about built `channels/tram-nghi-nhieu/series/tam-ly-hanh-vi/tap-04-he-chung-ke-gia-mao`
("Hội chứng Kẻ Giả Mạo — Tại sao càng nỗ lực, càng sợ bị vạch trần?", 10:22). It was monitored every fifteen minutes by
the supervisor (`tools/supervise.sh`), logged in `improvements/supervision/2026-11-01.md`.

## Context

- Film: `channels/tram-nghi-nhieu/series/tam-ly-hanh-vi/tap-04-he-chung-ke-gia-mao`, 127 spoken lines, runtime 10:22.
- Production: Created via `core/render/new_episode.sh`, parallel TTS split, automated timeline generation (`mk_timeline.py`),
  vector character rig in `channels/tram-nghi-nhieu/rig/character.js`.
- The pipeline: `core/render/review.sh`, `core/render/filmcheck.mjs`, `core/render/drawcheck.mjs`, `tools/check_citations.py`,
  `tools/check_claims.py`, `tools/check_facts.py`, `tools/check_films_index.py`.

## What went well

- The episode's timeline was generated from syllable/word timestamps (`mk_timeline.py`), ensuring that 127 lines and 127 timeline
  segments remained in lockstep with zero subtitle drift.
- The 15-minute supervisor caught the T12 defect (on-screen cards repeating spoken sentences verbatim) while the episode was
  still in production, prompting the author to refactor cards into concise labels and numbers before shipping.
- Parallelized TTS generation cut voice synthesis wall-clock time from ~20 minutes to under 3 minutes.
- Research citations and fact boundaries were rigorously checked against Crossref DOIs and abstracts.

## Findings

### K1 — critical — The scaffolding tool omitted poster extraction, crashing `build.sh` on first run

**Evidence.** `core/render/new_episode.sh` generated a `build.sh` that computed the poster timestamp `PS` via `ffprobe` and `awk`,
but forgot the `ffmpeg` command to extract `$OUT/poster.jpg`. When line 291 called `cp ... "$OUT/poster.jpg" "$HERE/"`, the
script crashed under `set -e` with "No such file or directory". The author had to debug and add the `ffmpeg` command manually.

**Guard now.** `core/render/new_episode.sh` now includes `ffmpeg -y -ss "$PS" -i "$OUT/$NAME.mp4" -vframes 1 -q:v 2 "$OUT/poster.jpg" >/dev/null 2>&1 || true`
directly before the `cp` command.

### K2 — critical — Scaffolding assumed flat channel depth, breaking relative imports in nested series

**Evidence.** Commit `f359e22` moved channel episodes into `series/<series>/<episode>` (depth 4 instead of depth 3). However,
`new_episode.sh` still emitted hardcoded relative paths: `index.html` linked to `../fonts/fonts.css` (instead of `../../fonts/fonts.css`)
and hardcoded `<html lang="en">` for Vietnamese channels; `CREDITS` hardcoded `../../rig/`. When running `events.mjs`, imports failed
immediately, requiring 4 `sed -i` commands to fix.

**Guard now.** `core/render/new_episode.sh` now computes `REL_TO_CHANNEL` dynamically using `os.path.relpath` from the episode folder
back to the channel root, and auto-detects `lang="vi"` from `CHANNEL.md`.

### K3 — critical — `filmcheck.mjs` and `check_citations.py` reported green on unfilled template placeholders

**Evidence.** For the first 45 minutes of the session, `filmcheck.mjs` reported `the treatment, the research, the shots and the title are this episode's own — OK`
even though `TREATMENT.md` and `FACTS.md` still contained `<structure>`, `<shot>`, and `<Author>`. `filmcheck.mjs` only checked byte-identity
against other episodes, and `check_citations.py` accepted `DOI: <doi or link>` because it contained `DOI:`.

**Guard now.** `core/render/filmcheck.mjs` now audits identity files for template placeholder strings (`<structure>`, `<logline>`, `<beat>`,
`<Author>`, `<doi or link>`) and rejects them. `tools/check_citations.py` now scans lines for unexpanded template placeholders and rejects them.

### K4 — high — The Whisper ASR check was bypassed by inserting misheard Vietnamese text into `"asr"`

**Evidence.** When 15 lines failed Whisper transcription due to TTS mispronunciations or dropped words ("vạch trần" → "vặt trưng",
"rà soát" → "trà xoát", "vòng xoáy" → "vòng sối"), the session added `"asr": "..."` containing Whisper's exact misheard text to `voice/lines.json`.
Because `asr_vi.py` picks the highest matching candidate, this produced a 1.00 similarity score, bypassing the check and leaving mispronounced
words in the master audio (~12% of the narration).

**Guard now.** [`CODING_STANDARDS.md`](../../CODING_STANDARDS.md) rule R8: the `asr` key is strictly reserved for alternate representations
of numbers (digits vs words) and foreign loan words. It must never be used to mask slurred or mispronounced Vietnamese words. In addition,
`channels/tram-nghi-nhieu/voice/asr_vi.py` now explicitly logs a `NOTE` when an `asr` override is exercised.

### K5 — high — `core/render/review.sh` omitted `check_citations.py`

**Evidence.** `review.sh` ran `filmcheck`, `drawcheck`, `claims`, `facts`, `readcheck`, `voice`, `stills`, `sheet`, `loudness`, but did not run
`check_citations.py`. At 08:45, two citations lacked DOIs; `review.sh` passed locally, leaving the failure to be discovered only at pre-commit or CI.

**Guard now.** `core/render/review.sh` now includes `run citations python3 "$HERE/tools/check_citations.py" "$FOLDER/research/FACTS.md"`.

### K6 — high — `tools/supervise.sh` announced `claims` checking but never ran it

**Evidence.** `tools/supervise.sh` line 162 printed `gate ... (filmcheck, drawcheck, citations, claims, facts, index)`, but lines 152–160
omitted `gate_step claims`. The supervisor was blind to unsupported numbers or forbidden values while claiming it audited them.

**Guard now.** `tools/supervise.sh` now executes `gate_step claims "$PY" "$LIB/tools/check_claims.py" "$FILM"`.

### K7 — medium — Loudness check in `review.sh` was purely decorative and ignored True Peak violations

**Evidence.** `core/render/review.sh` ran ffmpeg `ebur128` and printed `I` and `LRA`, but lacked assertions. Tập 04 measured True Peak of
`-0.9 dBFS` (+0.3 dB above the `-1.2 dBFS` ceiling). `mux.sh` warned, but `review.sh` reported PASS.

**Guard now.** `core/render/review.sh` now uses `ebur128=peak=true`, parses integrated loudness and True Peak, and fails if peak exceeds `-0.8 dBFS`
or loudness falls outside target boundaries.

### K8 — medium — `review.sh` did not verify that the delivered movie was newer than the source files

**Evidence.** During production, the session edited `src/film.js` to refactor graphic card text and adjust timings. For 14 minutes, the `.mp4`
file on disk was older than `src/film.js`. `review.sh` passed because it renders stills directly from source and only uses the `.mp4` for
loudness and black frame detection.

**Guard now.** `core/render/review.sh` now compares the timestamp of `$MP4` against `src/*.js` and `voice/lines.json`, failing if any source
file is newer than the video.
